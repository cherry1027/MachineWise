# MachineWise

Industrial Machinery Safety & Ergonomics Decision Support

MachineWise is a small two-page React prototype for comparing fictional converting machines across safety, ergonomics, automation, maintainability, reliability, and operational efficiency.

## Live Demo

https://machinewise-safety-prototype.charanvaranasi44.workers.dev/

## Features

### Machinery Assessment

- Select between three fictional machines
- View six engineering scores on a 0–10 scale
- Interactive radar chart
- Operational status assessment
- Green, yellow, and red indicators
- Automatically generated example findings

### Weighted Decision Matrix

- Adjustable criterion-weight sliders
- Weights automatically remain balanced at 100%
- Live weighted-score calculation
- Automatic machine ranking
- Strengths and improvement opportunities
- Preferred future machine requirements
- Three-machine radar comparison
